# Deploying a fully responsive frontend website for an educational insitute using Docker

## Overview

This is a simple comparison of how a dockerfile is written for Docker single-stage and multi-stage builds.

## Content

The directory contains 2 files:
`./Dockerfile.multistage`
`./Dockerfile.singlestage`

## What I learnt?

I learned how to write a Dockerfile for multi-stage builds and the practical advantage multi-stage builds have over single-stage builds. The major noticeable ddifference being the optimization of image size.
